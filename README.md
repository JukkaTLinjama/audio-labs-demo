# Headrest listening demo

Interactive public demo of headrest Program A, A/B listener monitoring, cabin noise, and bass feelness protection.

Open `index.html` through GitHub Pages. The demo includes procedural Bach; Music demo and Voice / narration files are selected locally by each visitor and are not uploaded.

## Audio path

Program A → bass protection → Listener A / A→B transfer → Demo VOL.

Scene and cabin ambient are independent shared layers. Demo VOL starts at −12 dB. Bass protection is referenced to Demo VOL 0 dB and defaults to −18 dBFS in the active demo.
